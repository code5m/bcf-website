# 同频商业计划与产品落地路线图

版本：2026-11-16；阶段：MVP 开发验证，尚未公开上线。

## 一句话定位
**本地收藏属于个人；公开精选由用户决定；以共同收藏建立真实关系。**

## 首批用户和价值假设
- 第一客群：B站重度知识/兴趣收藏用户（AI、编程、电影、摄影、英语等），收藏超过 100 条但整理、学习困难。
- 第二客群：愿意分享公开策展收藏的 UP主和主题社区管理者。
- 要验证的不是“AI 会总结”，而是“有人愿意把收藏变成公开名片，且共同兴趣真的促成好友与学习协作”。

## 产品漏斗与北极星指标
1. 当日成功导入至少 20 条私人收藏的用户占比。
2. 一周内主动公开至少 3 条精选收藏的用户占比（核心转化）。
3. 每个公开用户每周收到或发出的有效交友申请数。
4. 双向接受并交换至少 3 条消息的关系数量（核心社交成效）。
5. 第 7 / 30 天真实回访率、拉黑举报率、删除比例。
不要以虚假的匹配百分比和机器人账户提高留存。

## 商业试验
- 永久可用的本地收藏、基本标签、公开橱窗和基本交友保持免费，先构建流动性。
- 未来高级订阅试价 ¥19–39/月：高级学习规划、跨平台导入、个人语义检索、专业策展、协作知识库；定价为假设，不是收入预测。
- 创作者版：自己的视频知识库、授权素材、内容策展分析和订阅页面。
- 企业版：授权内部培训视频管理与知识库；不将用户私人收藏用于广告画像。
- 不出售用户完整收藏数据，不通过精准定位暗中匹配。

## 里程碑
### P0 当前 MVP
- 用户本地收藏、离线保存、备份与导入
- 手动精选公开收藏，关闭/开启可发现性
- 双方意愿的兴趣匹配、申请、聊天、拉黑和举报
- PWA 可安装的 Web 形态、基础自动测试

### P1 实际小范围试运营
- 生产认证：邮箱验证、找回密码、设备管理
- 生产持久存储、用户隔离、管理后台与审核申诉
- 删除/导出/保留策略、滥用与垃圾消息防护
- 邀请制小样本研究（20–30 人），不需要海量虚构社交关系
- 安全测试、可靠的实时消息以及可访问性

### P2 能力扩展
- 共同学习专题、协作进度和主动加入的主题群组
- 获权内容的字幕/知识检索、AI 推荐可解释性
- Android/iOS/HarmonyOS 客户端与小程序依实际需求逐端开发、构建和签名
- 商业付费和创作者方案试验

## 成本、安全与合规
首个自托管版本默认 Node.js 单进程、浏览器 IndexedDB + 服务端 JSON，无外部 AI API 成本；不等于公网可运营架构。生产需 HTTPS、可靠数据库、身份体系、消息保留及隐私处理、平台授权审核、内容和社交治理。针对未成年人和地理位置应采用更严格保护，首版设为 18 岁以上、只允许城市级自愿资料。


## 本轮产品优化的已实现能力（2026-11-17）
- 保留 BFC 本地数据，不自动访问 B站账号；电脑端在用户主动确认后，可从运行于 127.0.0.1:4198 的本机 BFC 工作台读取备份。
- BFC 专题、分类、观看状态和私人笔记兼容导入；标题缺失时标记「待补齐」，不伪造原视频标题。
- 个人精选橱窗仅主动发布，可一键撤下；默认不允许被发现。
- 同频发现依据共同公开视频和兴趣排序；无共同兴趣者默认不进入匹配推荐列表。
- 双向同意好友关系后可以发起结伴学习计划，包含 1–5 个自愿填写的目标；受邀人同意后双方分别打卡。这个过程不会上传个人私人收藏或笔记。
- 商业化仍处于产品验证期，无支付或订阅扣费；定价为待验证假设。
