# 同频正式 APP 与 BFC 私人初始化

## 正式 APP（比赛与普通用户）
打开 \`/tongpin/\`：只有「视频 / 遇见 / 消息 / 我的」四个入口。视频首页不提供导入 JSON、清空库或 BFC 工作台管理按钮；没有已导入视频时，显示公开精选或标注清楚的互动演示，不编造真实数据。

## 仅维护时初始化私人片单
需要拥有实际收藏文件的设备访问 \`/tongpin/?setup=1\`，才显示本地迁移和预览工具。此页面只是个人浏览器的私人数据初始化，不会提交数据到 GitHub，不会自动发布到社交服务。任意人都可看到入口，但只能选择其自己设备上的文件；本地 BFC 连接仅限回环网络和开发模式。

## 真实 BFC 完整 JSON 从哪里获得？
- BFC 专题工作台 \`/studio.html\` 的「导出完整收藏 JSON（视频 + 专题）」现在由 \`full-bfc-backup.js\` 创建包含视频主记录的 \`workbench_backup\` 文件。
- 下载文件名：\`bfc-complete-collection-YYYY-MM-DD.json\`，保存到**用户浏览器配置的下载目录**；点击浏览器下载记录（Ctrl+J）可查看确切路径。
- 历史版工作台下载的 \`my-video-library.json\` 仅有专题、分类、观看状态，**不是完整视频库**。如果已有此文件，不能将它当成全部收藏视频。
- BFC 服务端还有 \`/api/workbench/backup\` 端点，只有运行原 BFC 服务时才能访问。端点不代表磁盘中自动存在一个 JSON 文件。

导入时在设备本地解析和去重，可以筛选收藏夹、检查缺标题，确认后写入当前浏览器 IndexedDB；可撤销。初始化工具永不自动上传私人收藏、笔记或匹配详情。比赛演示（\`?demo=1\`）使用独立虚构数据并明确标注，与真实数据隔离。

## 核验提示
真实收藏依然不在 GitHub 仓库。更新这套导出代码不等于已经取得、导入用户个人收藏，也不证明 BFC 视频数据已经完整可读。
